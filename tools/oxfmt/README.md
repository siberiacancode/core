# 🦀 oxfmt

A shared Oxfmt configuration for consistent code formatting across projects.

## Installation

```bash
npm install --save-dev @siberiacancode/oxfmt
```

## Usage

Create `oxfmt.config.ts` in the project root:

```typescript
import { oxfmt } from '@siberiacancode/oxfmt';

export default oxfmt;
```
